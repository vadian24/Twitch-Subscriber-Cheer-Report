# Twitch Subscriber & Cheer Report

A Chrome extension for compiling Twitch subscription and cheer (Bits) activity from publicly accessible archived chat logs across a selected reporting period.

## What it does

- Helps review subscription and cheer activity across multiple dates without opening each day's public archive manually.
- Organizes the available log events into a report for the selected channel and period.
- Identifies dates with no archived logs so missing archives can be distinguished from reported activity.

## Data source and limitations

Reports depend on the availability and contents of a **third-party public chat-log archive**. Missing archives, incomplete logs, and differences between logged chat events and Twitch's own analytics can affect results. This tool is independent and is not affiliated with or endorsed by Twitch.

## Privacy

The extension is designed to process publicly accessible archive entries for the report you request, without sending those reports to the extension developer. Public logs can include usernames, which may be personal information.
