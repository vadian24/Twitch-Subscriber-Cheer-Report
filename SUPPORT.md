# Support — Twitch Subscriber & Cheer Report

For help, bug reports, or suggestions, [open a GitHub issue](https://github.com/vadian24/Twitch-Subscriber-Cheer-Report/issues/new).

When reporting a problem, include the extension version, the selected month, and a description of what occurred. You may include an error message, but **do not post passwords, private account information, or private chat logs**.

## Archive availability

Some dates do not have archived logs, for example when a channel did not stream or the archive is unavailable. A date listed as **No archived logs** does not necessarily mean that the extension failed.

## Privacy

See the [Privacy Policy](PRIVACY.md) for information about how the extension handles public log data.
